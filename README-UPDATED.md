# Anitayan Classes — Updated React Project

## Run locally

1. Install Node.js (LTS).
2. Open this project folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## What's updated

- New Anitayan Classes vector logo and favicon.
- Redesigned homepage with a responsive education-focused hero, exam discovery, feature cards, practice preview, educator section and admission/contact CTA.
- Navbar language switch (English / हिंदी).
- Light / dark theme switch.
- Language and theme preferences persist using localStorage.
- Translation support added for shared navigation, homepage, exam pages, notes, classes, contact, mock-test interface, test questions and payment/success copy.
- Existing routes, exam/notes/mock-test data and payment demo flow are retained.
- Payment UPI details, QR asset, pricing and purchase flow were not intentionally changed.

## Notes

- The payment flow remains a front-end demonstration as in the original project; no payment gateway or server-side verification was added.
- `node_modules` is intentionally not included. Run `npm install` after extracting the ZIP.
